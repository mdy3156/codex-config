# 日本語技術文書

依頼された原稿の範囲で、意味・根拠・不確実性を保ちながら文章を整える。読者、文体、用語、構成について指定があれば、それに合わせる。

## 基本の規範

- 一段落で一つの論点を展開し、段落間の論理関係を読み取れるようにする。
- 主張の範囲を根拠に合わせる。推量、仮定、反実仮想を根拠なく断定に変えない。
- 用語と定義を揃え、具体的な主体・処理・結果を書く。
- 内容を増やさない予告、称賛、強調、言い換えの反復を削る。
- 英語の比喩の直訳や抽象物の擬人化を避け、確認できる事実として表現する。
- 局所的な推敲では、その箇所とつながりの確認に必要な周辺を読む。章全体の書き直しへ広げない。

## 必要な規範を参照する

| 作業 | 参照先 |
| --- | --- |
| 論証、因果、対比、主張と根拠の確認 | [論証と根拠](references/argument.md) |
| 章・節・段落の構成、説明順序、重複、見出し | [構成と読み手の負荷](references/structure.md) |
| 語句、文末、視点、比喩、修辞の推敲 | [語句・文体・修辞](references/expression.md) |

全文の執筆・推敲では必要な観点を組み合わせる。限定的な修正では該当する参照先だけを読む。参照先には、この利用者の詳細な文章上の選好を保存している。

修正後は、意味や不確実性が変わっていないか、削った説明への言及が残っていないかを確認する。依頼された修正を終えたら、残る論点がある場合だけ具体的に示す。
